For GKY Citragarden's liturgist and for one native reader per language. Source of the words: `domain/seed.go`. A new church gets the set in its default content language; every entry is editable afterwards.

Questions:
1. Does the order above match a normal Sunday? What comes before the votum (prelude, welcome, announcements) and after the blessing (postlude)?
2. Which items does GKY have that we lack (for example Hukum Taurat, Pengakuan Dosa, Pengakuan Iman, Doa Bapa Kami, Warta Jemaat, Doa Persembahan, Perjamuan Kudus)?
3. How many songs come in a service, and where? Is each song its own item, or are they grouped (Pujian, Penyembahan)?
4. Is the order the same in every service (Ibadah Umum 1, 2, Youth), or does each have its own?
5. Which duties exist at GKY? Draft: Liturgis, Pemandu Pujian, Pemusik, Pembaca Alkitab, Pengkhotbah, Multimedia, Kolektan. Missing: usher, singer, translator, and so on?
6. Which singing parts are used when a song is sung? Draft: Semua, Pemandu, Jemaat, Pria, Wanita, Paduan Suara.
7. Which languages does a service use, and does the Mandarin service follow the same order?

## When this is done

The owner sends the answers back. Then `domain/seed.go` and [09 §3](09-planning.md#3-seeded-defaults-p-56) change in one commit, Q-3.3 is marked closed in the [index](README.md#4c-questions-for-the-owner-step-3), and the Spec Gate note in the index and in doc 09 is removed. Churches already seeded keep their rows (the seed marker); only new churches get the new words.
